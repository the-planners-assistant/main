# Contributing

This project is at an early foundation stage. Contributions, technical critique and reproducible research are welcome, but the architecture is not yet settled.

1. Check [existing issues](https://github.com/the-planners-assistant/main/issues) before beginning substantial work.
2. Open an issue describing the problem and proposed outcome before large changes, particularly new dependencies or architectural choices.
3. Work on a branch and submit a pull request linked to the issue. Draft pull requests are welcome.
4. Explain what changed, how it was tested, and whether the change affects provenance, licensing, security or compatibility.
5. Do not commit secrets, personal data, credentials, or third-party material without appropriate redistribution rights.

Changes are reviewed according to project needs. Maintainer decisions are recorded in version-controlled documentation when consequential.
