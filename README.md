# The Planner's Assistant

An independent, open-source project exploring computational tools and shared infrastructure for spatial planning.

The current engineering focus is an integrated environment for English Local Plan preparation, analysis, examination and monitoring. The project's scope, technical architecture and interfaces are being developed openly; proposed capabilities should not be mistaken for implemented functionality.

## Current status

**Foundation stage.** The repository currently contains project infrastructure and a basic website, not a functioning Local Plan application.
